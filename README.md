# Besbes Goals — Full PHP/MySQL edition

هذه النسخة تربط واجهة Besbes Goals بقاعدة MySQL وتضيف الحسابات، الصلاحيات، المنشورات، الملاعب، ورسائل التواصل كتذاكر.

## 1) قاعدة البيانات
افتح phpMyAdmin لقاعدة `s317862_Besbes` وشغّل:

- `schema.sql`

اسم جدول الحسابات هو `goals_accounts` (استخدام underscore هو الشكل الصحيح لاسم جدول MySQL).

## 2) الاتصال
بيانات MySQL الموجودة في `api/config.php` مأخوذة من بيانات الاتصال التي أرسلتها. لا تشارك هذا الملف علنًا.

## 3) أول Admin
كل تسجيل جديد يبدأ تلقائيًا كـ `player` كما طلبت.
بعد إنشاء حسابك، نفّذ في phpMyAdmin:

```sql
UPDATE goals_accounts SET role='admin' WHERE email='YOUR_EMAIL';
```

ثم سجّل الخروج والدخول مجددًا لتظهر لوحة الإدارة.

## الصلاحيات
- **player:** الواجهة العادية + يستطيع مراسلة صاحب الملعب، وتظهر الرسالة كتذكرة `001`, `002`, `003`...
- **stade_owner:** الواجهة العادية + `إضافة منشور` + استقبال التذاكر الخاصة بملاعبه.
- **admin:** كل ما سبق + `إضافة منشور` + `إضافة Admin`/تغيير الصلاحيات + `إضافة ملعب` + مشاهدة وإدارة التذاكر.

## رفع الموقع
ارفع الملفات والمجلد `api` إلى نفس مجلد الموقع. يجب أن يكون الاستضافة تدعم PHP 8+ وPDO MySQL.
