# Besbes Goals — Frontend Starter

هذا الإصدار هو واجهة Frontend أولية لمشروع Besbes Goals، مبنية بـ:
- HTML
- CSS
- JavaScript Vanilla

## التشغيل
افتح `index.html` في المتصفح.

## ملاحظات
الصور الحالية من Unsplash كمحتوى تجريبي. لاحقًا نستبدلها بصور الملاعب/اللاعبين الخاصة بالمشروع.
النسخة الحالية تركز على الواجهة والحركة فقط؛ الحجز والحسابات والبطولات ستُربط بالـBackend في المرحلة التالية.
